# Fuji Restaurante

Site de apresentação de um restaurante de culinária japonesa, desenvolvido em HTML e CSS. Reúne uma página inicial, um cardápio com imagens e preços e uma página de contato.

O cardápio organiza entradas, pratos e bebidas, com opções como sushi, temaki, yakisoba, gyoza e chá verde. A proposta é apresentar o restaurante e facilitar a consulta às suas opções gastronômicas.
